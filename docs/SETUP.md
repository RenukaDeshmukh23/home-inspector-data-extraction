# Viewing this repository

This is a documentation repository for a completed client engagement. It contains a case study and a synthetic JSON example, with no original scraper code or client data.

## Read without installing anything

Open `README.md` and `samples/synthetic-output.json` in GitHub or a text editor.

## Optional local inspection

Download the repository contents and open a terminal in the repository directory. If Python 3 is available, run:

```bash
python3 -m json.tool samples/synthetic-output.json
```

On systems that use `python` for Python 3, use that command instead. This formats the synthetic JSON locally and makes no network requests.

## Running the original scraper

The original scripts, source configuration and dependency versions are not included. Therefore, no scraper installation or execution instructions are provided. A future runnable demonstration would need its own source code, documented environment and verification, and would be labelled as a recreated demonstration.
